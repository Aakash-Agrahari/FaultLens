# FaultLens - AI-Powered Incident Intelligence

**Investigate. Understand. Resolve.**

**An AI-powered incident investigation and resolution platform.**

FaultLens aims to simplify software incident management by using AI agents to investigate application failures, analyze logs, identify potential root causes, and recommend solutions.

Instead of manually going through logs, metrics, and documentation, engineers can use FaultLens to automate much of the investigation process and make faster, evidence-based decisions.

### Key Features

- **Automated Incident Investigation:** Analyze application errors, logs, and system failures.
- **AI-Powered Root Cause Analysis:** Identify potential causes and provide evidence-backed explanations.
- **RAG-Based Knowledge Retrieval:** Retrieve relevant information from technical documentation and previous incidents.
- **AI Agents:** Use specialized tools and workflows to investigate and troubleshoot issues.
- **Intelligent Remediation:** Recommend fixes and execute approved actions in a controlled environment.
- **Incident Verification:** Validate whether the suggested resolution actually fixes the problem.
- **Observability & Evaluation:** Monitor AI performance, response quality, and execution traces.

### Tech Stack

- **Language:** Python
- **Backend:** FastAPI
- **AI & Agents:** LangChain, LangGraph
- **LLMs:** Ollama and free-tier LLM APIs
- **Embeddings:** Sentence Transformers
- **Database:** PostgreSQL + pgvector
- **Caching:** Redis
- **Evaluation:** Ragas
- **Observability:** Langfuse
- **Testing:** Pytest

### Development Approach

FaultLens is being developed with a focus on learning and implementing practical AI engineering concepts, including LLM integration, RAG, agent orchestration, tool calling, evaluation, and production reliability.

The project prioritizes free and open-source technologies, with no dependency on paid AI APIs or services.
